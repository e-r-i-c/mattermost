# Brisk

Brisk is a rebranded, separately deployed build of this repository's web client (`webapp/`), served behind a small proxy that talks to an unmodified Mattermost server.

- [PLAN.md](PLAN.md): deployment design, license and trademark analysis, branding inventory and work plan.
- [logo-concepts/](logo-concepts/): the four green logo concepts. Breeze (`1-breeze.svg`) is the current choice.

Brisk is built from Mattermost source code. Mattermost is a trademark of Mattermost, Inc. Brisk is not affiliated with or endorsed by Mattermost, Inc.
